# Definition of Done — Clube da Régua

Uma entrega só é considerada concluída quando atende aos critérios abaixo.

## Critérios Técnicos

- Código compila sem erros.
- Sem dados mockados na funcionalidade entregue.
- Integrado ao Supabase quando aplicável.
- Estados de loading, vazio e erro implementados.
- Não quebra fluxos já validados.
- Responsivo.

## Critérios de UX e Marca

- UX respeita a identidade visual oficial.
- A tela segue `BRAND_GUIDELINES.md`.
- Textos estão legíveis.
- Ação principal está clara.
- Estados de sucesso e erro usam mensagens amigáveis.

## Critérios de Entrega

- Testado manualmente.
- Commit realizado.
- Arquivos SQL necessários documentados.
- Limitações conhecidas informadas ao final da entrega.

## Checklist Rápido

- [ ] Compila.
- [ ] Sem mocks indevidos.
- [ ] Supabase integrado.
- [ ] Loading/vazio/erro.
- [ ] Responsivo.
- [ ] Visual alinhado à marca.
- [ ] Fluxos existentes preservados.
- [ ] Commit feito.
- [ ] Teste manual realizado.
