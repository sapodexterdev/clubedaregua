# Componentes — UX-001 Primeiro Acesso

## Componentes Principais

- Logo Clube da Regua
- Icone de coroa
- Icone de localizacao
- Icone de agenda
- Splash Screen
- Onboarding Slide
- Indicador de progresso
- CTA Primario
- CTA Secundario
- Search Bar
- Botao de filtros
- Barber Card
- Rating Badge
- Status Aberto/Fechado
- Distancia
- Bottom Navigation
- Empty State
- Loading State
- Error State

## Componentes de Conteudo

- Saudacao personalizada
- Headline de descoberta
- Texto de apoio
- Card de barbearia
- Foto da barbearia em formato 16:9
- Nome da barbearia
- Nota e quantidade de avaliacoes
- Proximo horario ou horario de fechamento

## Microinteracoes

- Transicao em fade entre telas.
- Animacao suave entre telas do onboarding.
- Indicador de progresso do onboarding.
- Efeito de elevacao no toque dos botoes.
- Feedback visual no CTA principal.

## Tokens Visuais Aplicados

- Fundo preto profundo.
- Cards em cinza escuro.
- Dourado em acoes principais e destaque.
- Texto branco para conteudo principal.
- Cinza medio para informacoes secundarias.
- Icones outline com cantos arredondados.
