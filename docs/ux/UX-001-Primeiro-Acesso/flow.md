## Descricao das Etapas

### 1. Splash

Tela inicial com a marca Clube da Regua, atmosfera premium e indicacao visual de carregamento.

### 2. Onboarding 1

Mensagem de descoberta: encontrar as melhores barbearias perto do usuario, com avaliacoes reais, horarios disponiveis e informacoes importantes.

### 3. Onboarding 2

Mensagem de agendamento: escolher servico, profissional e horario ideal sem complicacao.

### 4. Explorar Barbearias

Tela de transicao para reforcar que explorar e livre. Deve oferecer CTA principal para explorar barbearias e opcao secundaria para continuar sem cadastro.

### 5. Home Publica

Primeira tela operacional do app, com saudacao, busca, localizacao, filtros, lista de barbearias e navegacao inferior.

## Estados Previstos

- Carregando barbearias.
- Nenhuma barbearia encontrada.
- Erro de carregamento com acao para tentar novamente.

## Regras do Fluxo

- Cadastro nao deve ser exigido antes da Home Publica.
- O onboarding so deve ser exibido uma vez.
- O usuario deve sempre ter uma acao clara para avancar.
