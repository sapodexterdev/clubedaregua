# UX-002 — Descobrir Barbearias

## Objetivo

Permitir que o usuario encontre as melhores barbearias perto de si, compare opcoes e acesse as informacoes necessarias para iniciar um agendamento.

## Problema Resolvido

Transforma o app em uma experiencia discovery first. O usuario nao precisa conhecer uma barbearia previamente nem criar conta para navegar, pesquisar, filtrar e avaliar opcoes.

## Publico

Clientes que querem encontrar uma barbearia por proximidade, avaliacao, servico, preco, disponibilidade ou preferencia visual antes de escolher onde agendar.

## Resultado Esperado

O usuario deve conseguir pesquisar, aplicar filtros, comparar barbearias, abrir o perfil de uma barbearia e visualizar horarios disponiveis com poucos toques.

## Regras Importantes

- Navegacao livre sem login.
- Informacoes essenciais sempre visiveis nos cards.
- Perfil da barbearia deve abrir em uma unica acao.
- Acesso aos horarios em ate dois cliques.
- Acoes principais sempre em amarelo.
- O usuario pode favoritar apenas quando estiver autenticado.
- Imagens de barbearias devem manter proporcao 16:9.

## Relacao com o Brand Kit

Esta jornada aplica o visual urbano premium da marca: dark first, preto e grafite como base, amarelo para acao principal e status importante, Barlow Condensed em titulos e Inter no corpo de texto. Os cards, filtros e chips seguem linguagem premium com bordas discretas e iconografia outline.
