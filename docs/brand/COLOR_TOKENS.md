# Color Tokens - Clube da Régua

## Paleta Oficial

| Token | Hex | Uso |
| --- | --- | --- |
| `black` | `#0D0D0D` | Fundo principal dark first |
| `graphite` | `#1A1A1A` | Cards, barras e blocos principais |
| `graphiteLight` | `#2C2C2C` | Superfícies elevadas e campos |
| `gold` | `#F2C14E` | Ação principal, destaque e status importante |
| `white` | `#FFFFFF` | Texto principal sobre fundo escuro |
| `gray` | `#7A7A7A` | Texto secundário e bordas discretas |

## Regras de Uso

- O fundo principal deve priorizar `black`.
- Cards devem usar `graphite` ou `graphiteLight`.
- `gold` não deve ser usado como cor dominante.
- `white` deve garantir leitura em áreas escuras.
- `gray` deve ser usado para informação secundária, nunca para texto essencial sem contraste adequado.

## Proibições

- Não criar nova paleta sem atualizar `docs/brand/`.
- Não trocar dourado por laranja, amarelo neon ou tons genéricos.
- Não usar telas majoritariamente claras sem justificativa aprovada na documentação.
