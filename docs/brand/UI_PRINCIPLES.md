# UI Principles - Clube da Régua

## Fonte Oficial

Toda decisão de UI deve partir do `docs/brand/Brand_Kit_v2.png`, dos documentos em `docs/brand/` e dos UX Boards aprovados.

## Princípio Central

A interface do Clube da Régua deve ser **dark first**, urbana, premium e operacional.

O produto precisa parecer uma ferramenta de gestão moderna para barbearias, sem perder personalidade.

## Regras de Interface

- Usar fundos pretos ou grafite como base.
- Usar cards escuros com borda discreta.
- Manter textos claros e legíveis.
- Usar amarelo apenas para ação principal, destaque e status importante.
- Evitar excesso de amarelo.
- Evitar interfaces claras como padrão.
- Evitar estilos genéricos que não remetam ao universo da marca.
- Cliente e Gestão devem parecer partes do mesmo produto.

## Botões

- Botão primário: fundo `#F3B200`, texto escuro.
- Botões secundários: fundo grafite, borda discreta e texto claro.
- Ação destrutiva deve ser clara, mas sem competir visualmente com a ação principal.

## Cards

- Fundo preferencial: `#18181B` ou `#27272A`.
- Borda discreta.
- Raio moderado.
- Espaçamento interno confortável.
- Não usar cards brancos como padrão visual.

## Estados

Toda tela relevante deve prever:

- Loading.
- Lista vazia.
- Erro.
- Sem internet quando aplicável.
- Sucesso após ações importantes.

## Consistência

Componentes equivalentes devem manter comportamento, espaçamento, cor e hierarquia visual entre App Cliente e App Gestão.
