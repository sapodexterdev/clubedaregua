# UI-008 — Ver Horários

## Objetivo

Permitir que o cliente combine serviço, profissional, data e horário disponível antes de avançar à confirmação.

## Status

Em validação no Preview.

## Origem

- Jornada: `UX-002 — Descobrir Barbearias`.
- Entrada: CTA do Perfil da Barbearia.
- Próxima etapa: dados e confirmação do agendamento.

## Princípios

- disponibilidade consultada no banco;
- fluxo público até o avanço para confirmação;
- escolhas visíveis e reversíveis;
- nenhum horário antigo durante uma nova consulta;
- estados distintos para carregamento, erro e agenda vazia.
