# UI-013 — Perfil do cliente

## Objetivo

Oferecer ao cliente autenticado um ponto seguro e funcional para consultar e atualizar os dados da própria conta.

## Status

Implementado, aguardando validação visual e funcional no Preview.

## Princípios

- dados reais do usuário autenticado;
- nenhuma pontuação, cupom ou notificação simulada;
- edição protegida pelas regras RLS de `profiles`;
- recuperação de senha pelo e-mail confirmado;
- saída da conta com confirmação.
