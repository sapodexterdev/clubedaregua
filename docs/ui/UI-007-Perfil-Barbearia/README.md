# UI-007 — Perfil da Barbearia

## Objetivo

Apresentar uma barbearia com clareza e confiança, permitindo comparar serviços e profissionais antes de avançar aos horários.

## Status

Em validação no Preview.

## Origem

- Jornada: `UX-002 — Descobrir Barbearias`.
- Entrada: card ou resultado da Home Pública.
- Próxima etapa: escolha de serviço, profissional e horário.

## Princípios

- dados reais, sem avaliações, imagens ou disponibilidade inventadas;
- capa em proporção visual 16:9;
- identidade dark first com amarelo reservado à ação;
- CTA de horários fixo e sempre acessível;
- navegação pública até a confirmação de uma ação protegida.
