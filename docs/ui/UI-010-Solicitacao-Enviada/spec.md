# Spec — UI-010 Solicitação Enviada

## Estrutura

1. marca de sucesso outline;
2. título `Solicitação enviada`;
3. status `Aguardando confirmação`;
4. resumo com barbearia, serviço, profissional, data, horário e valor;
5. linha do tempo dos próximos passos;
6. CTA para voltar à descoberta.

## Regras funcionais

- abrir somente após retorno positivo da gravação;
- acesso sem solicitação recente exibe estado seguro;
- voltar à Home limpa a pilha de navegação;
- não afirmar que o horário está confirmado;
- não oferecer Agenda enquanto ela não estiver conectada aos dados reais.

## Visual

- amarelo indica sucesso recebido e status pendente;
- superfícies em grafite com borda discreta;
- títulos em Barlow Condensed;
- corpo de texto curto, direto e sem linguagem promocional excessiva.
