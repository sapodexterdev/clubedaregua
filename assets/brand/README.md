# Assets oficiais — Clube da Régua

Esta pasta contém os arquivos oficiais aprovados do Brand Kit V2.

## Estrutura

- `logos/`: assinatura principal, versões monocromáticas e símbolo reduzido.
- `app-icon/`: ícone mestre do aplicativo e favicons.
- `elements/`: padrão de régua, iconografia complementar e navalha isolada
  derivada diretamente da assinatura oficial para animações.
- `tokens/`: tokens CSS e JSON da identidade visual.

## Regras

- A logo não deve ser recriada, redigitada ou reorganizada.
- Utilize os SVGs como arquivos mestres.
- O amarelo oficial é `#F3B200`.
- O fundo dos logos e símbolos é transparente.
- O fundo escuro do ícone do aplicativo faz parte do desenho.
- Novas telas devem usar exclusivamente os arquivos desta pasta.

Consulte `docs/brand/Brand_Kit_v2.png` e `docs/brand/BRAND_GUIDELINES.md` antes de qualquer aplicação visual.
