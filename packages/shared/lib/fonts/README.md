# Fontes do produto

As fontes são empacotadas no pacote compartilhado para que Cliente e Gestão
tenham a mesma renderização, inclusive no Safari/PWA e sem dependência de rede.

| Família | Arquivo | Peso | Origem |
| --- | --- | --- | --- |
| Inter | `Inter-Variable.ttf` | 100–900 | `google/fonts/ofl/inter` |
| Barlow Condensed | `BarlowCondensed-SemiBold.ttf` | 600 | `google/fonts/ofl/barlowcondensed` |
| Barlow Condensed | `BarlowCondensed-Bold.ttf` | 700 | `google/fonts/ofl/barlowcondensed` |
| Barlow Condensed | `BarlowCondensed-ExtraBold.ttf` | 800 | `google/fonts/ofl/barlowcondensed` |

Ambas são distribuídas sob a SIL Open Font License 1.1. As licenças completas
estão em `OFL-Inter.txt` e `OFL-BarlowCondensed.txt`.

Não substituir esses arquivos por downloads de sites de terceiros. Atualizações
devem registrar a origem, licença, pesos e validação visual nos breakpoints
oficiais.
