# Prompts — Clube da Régua

Todos os prompts enviados ao Codex devem ser salvos nesta pasta.

## Padrão de Nome

Usar o padrão:

- `issue-001.md`
- `issue-002.md`
- `issue-003.md`

Seguir a numeração oficial do MVP ou da sprint correspondente.

## Cabeçalho Obrigatório

Toda nova issue enviada ao Codex deve começar com:

```md
IMPORTANTE:
Este projeto segue obrigatoriamente o arquivo BRAND_GUIDELINES.md.
Nenhuma alteração visual pode ignorar a identidade oficial do Clube da Régua.
```

## Objetivo

Manter histórico claro de decisões, escopo e comandos enviados ao Codex para permitir auditoria, continuidade e rastreabilidade do produto.
